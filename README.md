#  Resume Screening System using NLP

##  Project Overview

This project implements a Resume Screening System that automatically classifies resumes into relevant job categories using Natural Language Processing (NLP) and Machine Learning techniques. It helps streamline the recruitment process by reducing manual effort in shortlisting candidates.

##  Objective

To build a machine learning model that can analyze resume text and predict the most suitable job role based on skills and content.

##  Technologies Used

* Python
* Pandas & NumPy
* Scikit-learn
* Natural Language Processing (NLP)
* TF-IDF Vectorization

##  Methodology

1. Data Loading and Exploration
2. Text Preprocessing (lowercasing, removing special characters)
3. Feature Extraction using TF-IDF
4. Model Training using Naive Bayes / Logistic Regression
5. Model Evaluation using Accuracy, Precision, Recall, and F1-score

##  Results

* Achieved an accuracy of approximately **56%**
* Moderate performance due to:

  * Variability in resume formats
  * Overlapping skills across different job roles


##  Dataset

Dataset used: **Resume Dataset (Kaggle)

>  Note: The dataset is not included in this repository due to size limitations.
> Please download it from Kaggle and place it in the same directory before running the notebook.

##  How to Run

1. Download the dataset from Kaggle
2. Place `resume.csv` in the project folder
3. Open the notebook (`task3_resume_screening.ipynb`)
4. Run all cells sequentially
